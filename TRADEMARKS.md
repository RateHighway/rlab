# Names, compatibility claims and marks

Use RevenueLab for the builder program and RevenueLab Pages for the generic
page concept. A RevenueLab Page inside RateMonitor Elite is an RME Custom
Page. The format is written `.rlab`.

Accurate descriptive statements such as "supports the .rlab format" are
welcome. State the exact profile, product release, evidence and limitations.
Do not suggest that package validation establishes a certified or secure host.

The source license does not authorize using RateHighway or RevenueLab logos,
adding those names to another product's branding, or implying endorsement.
No logo assets are distributed in this repository. Use your own product name
and identity.

"RateHighway certified" and certification badges require an actual separate
issuance covering the named release and scope. No certificate is issued by
the schemas, tools or examples. This policy makes no claim that `.rlab` is a
registered trademark.
